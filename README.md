# Renamer

[![GitHub release](https://img.shields.io/github/v/release/Fallmore/Renamer)](https://github.com/Fallmore/Renamer/releases)
[![.NET 10](https://img.shields.io/badge/.NET-10.0-512BD4?logo=dotnet)](https://dotnet.microsoft.com/download/dotnet/10.0)

Консольная утилита для пакетного переименования файлов: находит указанные символы (или их последовательности) в названиях файлов и заменяет их по заданному правилу — например, убирает пробелы, меняет пробелы на подчёркивания или обрезает имя на нужном символе.

[Возможности](#возможности) • [Установка](#установка) • [Использование](#использование) • [Поведение](#поведение) • [Публикация](#публикация-один-файл) • [Разработка](#разработка)

## Возможности

* Замена всех вхождений символа в имени — одним проходом по папке.
* Несколько искомых символов за один запуск: `-s " " "-" "."`.
* Три режима замены: только символ, всё до символа, всё после символа.
* Обработка вложенных папок через флаг `--all-directories`.
* Предпросмотр без риска: `--dry-run` показывает, что изменится, не трогая файлы.
* Автоматическое разрешение конфликтов имён: ` (1)`, ` (2)` и т. д.
* Понятный результат: каждая пара `старое имя => новое имя`.
* Работает на .NET 10, публикуется одним файлом `renamer.exe`.

## Установка

### Готовая сборка

1. Скачайте архив с последнего релиза на странице [Releases](https://github.com/Fallmore/Renamer/releases).
2. Распакуйте его в любую папку.
3. Убедитесь, что установлен [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) — сборка выполняется без встроенного рантайма.

Готово: запускайте `renamer.exe` из командной строки.

### Сборка из исходников

Требуется [.NET SDK 10.0](https://dotnet.microsoft.com/download) или новее:

```bash
git clone https://github.com/Fallmore/Renamer.git
cd Renamer
dotnet build -c Release
```

Собранный файл: `Renamer\bin\Release\net10.0\renamer.exe`.

Запуск без сборки:

```bash
dotnet run --project Renamer -- rename -d "C:\path\to\folder" -s " " -r "_"
```

## Использование

```text
renamer rename [опции]
```

### Быстрый старт

Заменим пробелы на подчёркивания в названиях файлов папки `D:\photos`:

```console
> renamer rename -d "D:\photos" -s " " -r "_"
Успех! Переименовано 2 файлов
My photo
	=>	My_photo
My photo 2
	=>	My_photo_2
```

Имена в выводе приведены без расширения — расширение файла при переименовании сохраняется.

### Опции

| Опция | Короткая | По умолчанию | Описание |
|---|---|---|---|
| `--dir` | `-d` | — | Папка, в которой находятся файлы (обязательная; папка должна существовать) |
| `--symbols` | `-s` | — | Символы (или их последовательности), которые нужно найти в названии файла (обязательная; можно указать несколько через пробел) |
| `--replace` | `-r` | пустая строка | Чем заменить найденные символы |
| `--mode` | `-m` | `OnlySymbol` | Режим замены (см. ниже) |
| `--all-directories` | `-ad` | выключено | Обрабатывать файлы всех подпапок; без флага — только файлы указанной папки |
| `--dry-run` | `-n` | выключено | Показать результат без фактического переименования файлов |

Чтобы удалить символы, `--replace` можно не указывать вовсе — по умолчанию это пустая строка.

### Режимы замены (`--mode`)

| Режим | Поведение | `My file.txt` → `-s " "` |
|---|---|---|
| `OnlySymbol` | Заменить найденные символы на `--replace` | `My_file.txt` (при `-r "_"`) |
| `BeforeSymbol` | Удалить всё до найденного символа, вставив `--replace` вместо удалённой части | `file.txt` |
| `AfterSymbol` | Обрезать имя на найденном символе и дописать `--replace` | `My.txt` (при `-r ""`) |

### Примеры

Убрать пробелы из названий:

```bash
renamer rename -d "D:\photos" -s " "
```

Заменить пробелы на подчёркивания во всех подпапках:

```bash
renamer rename -d "D:\photos" -s " " -r "_" -ad
```

Обрезать имя на символе `-` (режим `AfterSymbol`):

```bash
renamer rename -d "D:\photos" -s "-" -m AfterSymbol
```

Удалить точки, запятые и точки с запятой из названий:

```bash
renamer rename -d "D:\photos" -s "." "," ";"
```

Посмотреть, что изменится, без самого переименования:

```console
> renamer rename -d "D:\photos" -s " " -r "_" -n
Предпросмотр (dry-run): было бы переименовано 2 файлов, файлы не изменялись
My photo
	=>	My_photo
My photo 2
	=>	My_photo_2
```

### Справка

```bash
renamer --help        # описание программы и список команд
renamer rename --help # описание опций команды rename
renamer --version     # версия программы
```

## Поведение

* Обрабатываются только имена без расширения; расширение файла сохраняется.
* Файлы без расширения обрабатываются наравне с остальными.
* Заменяются все вхождения искомого символа в имени.
* Если после замены имя не изменилось, файл пропускается.
* Если новое имя уже занято другим файлом, к нему добавляется суффикс вида ` (1)`, ` (2)` и т. д.
* В режиме `--dry-run` файлы не изменяются, а занятые имена учитываются так же, как при реальном запуске.
* Результат выводится в консоль: итоговое количество и пары `старое имя => новое имя`.
* При ошибке на конкретном файле программа сообщает, на каком файле остановилась; уже переименованные файлы остаются с новыми именами.
* Без флага `--all-directories` подпапки не обходятся.
* В режиме `BeforeSymbol` для многосимвольной последовательности удаляется всё до её начала плюс первый символ последовательности — хвост остаётся в имени.
* В Windows PowerShell 5.1 пустая строка как аргумент (`-r ""`) отбрасывается самой оболочкой и вызывает ошибку разбора: просто не указывайте `-r` или используйте `cmd` / PowerShell 7+.

## Публикация (один файл)

Чтобы получить один переносимый `renamer.exe` (без папки с dll):

```bash
dotnet publish Renamer -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Результат: `Renamer\bin\Release\net10.0\win-x64\publish\renamer.exe`.

Промежуточные файлы обычной сборки в `bin\Release\net10.0\` и `bin\Release\net10.0\win-x64\` для запуска не нужны — рабочая публикация лежит только в подпапке `publish`.

Параметр `--self-contained false` означает, что .NET Runtime не встраивается в файл — на целевой машине должен быть установлен [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0). Чтобы собрать полностью автономный exe (работает без установленного рантайма, но весит заметно больше), замените флаг на `--self-contained true`.

Отладочные символы в проекте настроены как внедрённые в сборку (`DebugType=embedded`), поэтому отдельных файлов `.pdb` не появляется — они доступны в самом `renamer.dll`/`renamer.exe`.

## Разработка

### Структура проекта

```text
Renamer/
├── Renamer.slnx          # решение
├── LICENSE               # лицензия MIT
├── Renamer/
│   ├── Program.cs        # точка входа и описание команды rename
│   ├── FileRenamer.cs    # логика переименования и замены символов
│   ├── Mode.cs           # режимы замены
│   ├── RenameInfo.cs     # результат переименования
│   ├── RenamedFile.cs    # пара «старое имя → новое имя»
│   └── Renamer.csproj    # проект (net10.0, System.CommandLine 2.0.14)
└── Renamer.Tests/        # юнит-тесты (NUnit)
    ├── FileRenamerReplaceTests.cs   # замена символов
    └── FileRenamerRenameTests.cs    # переименование файлов
```

### Тесты

```bash
dotnet test Renamer.slnx
```

Покрыто логикой: режимы замены, все вхождения символов, конфликты имён, рекурсия, dry-run, файлы без расширения, а также регрессии на бесконечный цикл и пропуск соседних символов.

### Используемые технологии

* [.NET 10](https://dotnet.microsoft.com/)
* [System.CommandLine 2.0.14](https://www.nuget.org/packages/System.CommandLine/) — разбор аргументов командной строки
